## Key Finding

The ENS DAO is **fiscally robust and control-deficient** — strong treasury, broken budget binding. Recommended path: publish forensic ledger immediately, reject sole-source Retro, adopt Thin WG hybrid + Zero-Variance policy + competitive qualitative synthesis.
